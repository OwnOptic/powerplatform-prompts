Create a weekly timesheet app for professional services employees. The app should display the current week (Monday to Friday) with a row for each day. For each day, employees can add one or more time entries by selecting a project from a list, selecting a task type (Development, Design, Meeting, Admin, Support), entering the number of hours, and adding an optional note. The app should show a running total of hours per day and for the week. Include a submit button that locks the timesheet for the week and routes it to the employee's manager for approval. Show a history screen with previous weeks' timesheets and their approval status (Pending, Approved, Rejected). Store all data in Dataverse.
